# Aircraft-Operation-Landings-and-Weight-Metrics-Dataset
This dataset captures monthly aircraft operations including landings, total aircraft movements, aircraft types, operators, and associated weight metrics. It provides a detailed view of traffic volume, fleet composition, and operational load paterns across airlines and aircraft categories.

## **The dataset enables analysis across:**

- Aircraft types and manufacturers.

- Landing frequencies and aircraft movements.

- Airline fleet usage patterns.

- Weight and capacity distribution.

- Monthly and seasonal traffic trends.

- Anomaly detention on operational metrics.

- Correlation an statistical behavior.

- Pivot-table-style performance rankings.

## Objectives
This analysis aims to:
Identify the busiest aircraft types and airlines.   
understand weight distributionand capacity usage.     
Evaluate manufacturer and fleet-mix trends.   
Detect anomalies in aircraft weights or operational patterns.   
Build ranking dashboards for top peformers.    
Visualize geographc and temporal behavior.   
Generate pivot-table-style summaries.

- Month-over-month changes.
